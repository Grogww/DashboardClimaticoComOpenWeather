Architecture

Pattern: MVC (Model-View-Controller)

Flow: Browser → Express Server → OpenWeather API

OpenWeather API Info

Base URL: https://api.openweathermap.org/data/2.5

Endpoints consumed by server:

GET /weather?lat={lat}&lon={lon}&units=metric&lang=en&appid={key}

GET /forecast?lat={lat}&lon={lon}&units=metric&lang=en&appid={key}

Auth: API Key via query parameter (appid) — stored in .env, never exposed to client

Versioning: Path-based (/data/2.5/)

HATEOAS: No

Response format: JSON

Internal API (this server)

GET /api/weather?lat={lat}&lon={lon}
